# VIY Studio — Royal Neon

## Concepto
Royal Neon × Futuristic Glow: una identidad creativa, audaz y elegante con emblema de serpiente coronada.

## Paleta digital
- Negro profundo: #05020A
- Fucsia neón: #FF19C8
- Violeta: #8B35FF
- Azul eléctrico: #078BFF
- Oro: #FFBD45
- Blanco cálido: #FFF8FF

## Tipografía
- Logotipo: serif de alto contraste y cursiva elegante.
- Interfaz: sistema sans-serif legible.

## Versiones
- logo-principal.svg: marca principal en fondo negro.
- monograma-viy.svg: icono cuadrado para avatar y favicon.
- portada-redes.svg: composición horizontal para portada.

## Usos
Usar el emblema completo en fondos negros. Para tamaños pequeños, usar el monograma. Mantener espacio libre equivalente al 10% del ancho del logo. No deformar, recolorear parcialmente ni colocar sobre fondos con poco contraste.

## Impresión
Los SVG son escalables. Para imprenta, convertir a PDF y solicitar conversión profesional a CMYK según el perfil de color de la imprenta; los colores neón en pantalla no se reproducen exactamente en CMYK. Hacer prueba de color antes de tirajes grandes.

## Aplicación web
Usar negro como base, degradados fucsia-violeta-azul para acciones principales y oro solo para acentos premium. Respetar contraste y movimiento reducido del sistema.
